The learner finds the first invalid step and checks their own correction on a new problem.

## How to use

Open the [English prompt](en/math-error-analysis.md) and paste it into a new chat. Supply the required inputs and select the mode. Editable DOCX depends on the chat’s file tools. Markdown is the text fallback.

## Example

Secondary: a learner squares √(x + 2) = x and lists two candidates. Ask which candidates need checking and where.

## Status and materials

A written prompt for secondary and university education. Behaviour in specific models and file generation have not been tested. The chat provider processes your materials. Use public or anonymised sources.
